Proyecto 03 Completado

TechStore

API y frontend para una tienda de computadores y accesorios: catálogo público, panel de administración y gestión de pedidos con control de stock.

Problem

Una tienda necesita mostrar su catálogo sin exponer datos internos y, al mismo tiempo, registrar pedidos sin vender productos que no tiene en existencia.

Solution

Un backend en Spring Boot con seguridad JWT y permisos por módulo. El catálogo es público y oculta el stock mínimo; cada pedido valida existencias, copia el precio, calcula el total y descuenta el stock, y cancelarlo devuelve las unidades.

Technologies

  • Java 21
  • Spring Boot 4
  • Gradle
  • Spring Security
  • JWT
  • PostgreSQL
  • Swagger
  • H2
  • HTML
  • CSS
  • JavaScript

Features

  • Catálogo público sin inicio de sesión, con filtros por categoría y nombre.
  • Permisos granulares por módulo: categorías, artículos y pedidos.
  • Pedidos que validan stock y calculan el total; la cancelación devuelve las unidades.
  • Reporte de artículos con stock bajo para el administrador.
  • Regla de integridad: no se puede eliminar una categoría que tenga artículos.
  • 11 pruebas automatizadas sobre H2, incluido el flujo de stock y permisos.
