Proyecto 04 MVP

Chatbot de ventas en Telegram

Agente conversacional construido en n8n que atiende clientes por Telegram las 24 horas: responde precios y disponibilidad, recomienda planes de plataformas de streaming y guía el proceso de compra. Desarrollado en equipo.

Problem

Responder a mano las mismas preguntas de precios, stock y planes consume tiempo y deja a los clientes sin respuesta fuera del horario de atención.

Solution

Un flujo de n8n con un AI Agent conectado a Telegram, un modelo de OpenRouter, memoria de conversación y un catálogo en JSON como fuente de precios y existencias.

Technologies

  • n8n
  • Telegram Bot API
  • OpenRouter
  • AI Agent
  • JSON

Features

  • Respuestas automáticas sobre precios, disponibilidad y características de cada plan.
  • Recomendaciones según lo que pide el cliente.
  • Memoria conversacional para mantener el contexto del chat.
  • Proceso de venta guiado: saludo, necesidades, recomendación, precio, comprobante y confirmación.
  • Catálogo en JSON fácil de actualizar sin tocar el flujo.
