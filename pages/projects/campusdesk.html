Proyecto 02 Completado

CampusDesk

Plataforma web de mesa de ayuda para TechNova Solutions. Los usuarios reportan incidencias de hardware, software, redes o accesos, y el equipo técnico las atiende siguiendo un ciclo de vida controlado por el backend. Proyecto desarrollado en un equipo de cuatro personas.

Problem

Las incidencias tecnológicas de una organización se reportan por canales informales, sin un responsable asignado ni trazabilidad de su estado.

Solution

Un sistema de tickets con tres roles (usuario, técnico y administrador), asignación de técnicos, comentarios, historial inmutable de cambios de estado y calificación del servicio una vez cerrado el ticket.

Technologies

  • Java 17
  • Spring Boot 3.3
  • Spring Security
  • JWT
  • Spring Data JPA
  • PostgreSQL
  • Swagger
  • JUnit 5
  • Mockito
  • HTML
  • CSS
  • JavaScript

Features

  • Ciclo ABIERTA → ASIGNADA → EN_PROCESO → RESUELTA → CERRADA validado en el backend.
  • Autenticación con JWT y permisos distintos para usuario, técnico y administrador.
  • Comentarios e historial de cambios de estado por ticket.
  • Esquema SQL con restricciones CHECK, triggers y una vista de estadísticas.
  • Validación del entorno al arrancar: falla rápido si falta configuración o la base no responde.
  • Pruebas con JUnit 5, Mockito y AssertJ; API documentada con Swagger.
